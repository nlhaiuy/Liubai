# 留白

横屏看 4:3 视频时，把屏幕左右两侧的黑边盖成白色；也可在竖屏播放 16:9 视频时，把屏幕上下的黑边盖成白色（悬浮窗遮罩，不修改视频本身）。

## 构建
- Android Studio 直接打开本目录，Run 即可；或命令行 `gradle assembleDebug`（需要 JDK 17 + Android SDK）。
- 没有环境：把本目录推到 GitHub，Actions 会自动构建，在 Artifacts 里下载 `app-debug.apk`。

## 使用
1. 打开 App，点右上角的总开关，按提示授予“显示在其他应用上层”权限。
2. 回到视频 App 横屏播放；遮罩宽度 = (屏幕宽 − 屏幕高×比例) / 2。
3. 不贴合时用“宽度微调”：滑条、加减按钮，或点中间的大数字直接输入。
4. 底部大按钮是“竖屏遮罩”开关：开启后，竖屏播放时盖住视频上方和下方（视频按 16:9、撑满屏幕宽度），“视频位置”可选“16:9 居中”、“视频靠上”（直播间那种视频在上、聊天在下的布局）或“状态栏下”（B 站、抖音那种视频顶边紧贴状态栏下沿的布局，按手机的状态栏高度换算）。竖屏时没有滑条，演示小手机居中，直接在手机上上下滑动就能移动视频，点手机的上半部分上移 1dp、点下半部分下移 1dp（按住连续调），整张演示卡和横屏一样大。竖屏的微调是“移动视频位置”：在所选预设的基础上，往上滑视频就往上移（最多到贴顶，往下最多到贴底，整个屏幕高度都能到），不会改变遮罩的总厚度；换预设时微调回到 0。横屏的微调仍是调遮罩宽度。横屏、竖屏的微调分开保存；关闭则竖屏不盖，横屏仍盖左右两侧。
5. “生效范围”选“白名单”时，只在你勾选的视频软件里自动显示，需要开启无障碍（点提示条会直接跳到留白的无障碍页）；选“全局”则开启后到处显示。
   - 白名单横屏、竖屏各一份：设置页当前在编辑哪一侧（底部大按钮切换），“生效范围”就是哪一侧的白名单。竖屏没单独设置过时沿用横屏那份。
6. “显示时机”选“仅播放时”：白名单软件里只在它真的在播放时显示，一暂停就立刻收起。识别方式按可用程度自动选最准的一种：
   - **Shizuku**（可选）：安装并启动 Shizuku、在留白里授权后，能精确知道是哪个软件在播放，抖音、快手这类不规范使用媒体会话的软件也认得出。重启手机后需要重新启动 Shizuku。
   - Shizuku 授权给留白之后，悬浮窗、通知、后台运行、无障碍、通知使用权这些权限，点“开启”就由 Shizuku 直接开启，不用再跳系统设置页；个别系统开启后没生效时，会自动退回原来的系统授权页。
   - **媒体会话**（可选）：授予“通知使用权”后，读取各软件的播放状态。只用来读播放状态，不读取任何通知内容。
   - **系统音频**（无需授权）：只能判断手机有没有媒体声音在播，配合前台软件使用。
   - 三种方式都识别不到无声视频。不需要这个功能就保持“始终显示”，此时完全不监听播放状态。

## 自动更新
- 推到 `main` 后，GitHub Actions 会构建并发布一个 Release（标签 `v1.0.<构建号>`，安装包 `Liubai.apk`）；App 靠它判断有没有新版本。
- 设置页最下面的“软件更新”：选“自动更新”，打开 App 时会检查，另外每 6 小时在 Wi-Fi 下后台检查一次，有新版本就自动下载并安装；选“手动”则只在你点右边的状态时才更新。
- **装了 Shizuku 并已授权给留白时，更新由 Shizuku 以 shell 身份静默安装（pm install -r），所有系统版本都不弹确认，也不需要“安装未知应用”权限**；Shizuku 没启动（比如刚重启手机）或安装失败时，自动退回下面的系统安装器流程。
- 没有 Shizuku 时，第一次需要在系统里允许留白“安装未知应用”（点状态会直接跳到那一页）。
- Android 12 及以上：由留白装上的更新之后可以不弹确认、直接装好；第一次、以及 Android 11 及以下，系统要求点一下“更新”确认，后台时会用通知提醒。
- 带有自动更新的版本是第一版，需要先手动安装一次；之后才会自动更新。

# 留白

横屏看 4:3 视频时，把屏幕左右两侧的黑边盖成白色；也可在竖屏播放 16:9 视频时，把屏幕上下的黑边盖成白色（悬浮窗遮罩，不修改视频本身）。

## 构建
- Android Studio 直接打开本目录，Run 即可；或命令行 `gradle assembleDebug`（需要 JDK 17 + Android SDK）。
- 没有环境：把本目录推到 GitHub，Actions 会自动构建，在 Artifacts 里下载 `app-debug.apk`。

## 使用
1. 打开 App，点右上角的总开关，按提示授予“显示在其他应用上层”权限。
2. 回到视频 App 横屏播放；遮罩宽度 = (屏幕宽 − 屏幕高×比例) / 2。
3. 不贴合时用“宽度微调”：滑条、加减按钮，或点中间的大数字直接输入。
4. 底部大按钮是“竖屏遮罩”开关：开启后，竖屏播放时盖住视频上方和下方（视频按 16:9、撑满屏幕宽度），“视频位置”可选“16:9 居中”或“视频靠上”（直播间那种视频在上、聊天在下的布局）。横屏、竖屏的微调分开保存；关闭则竖屏不盖，横屏仍盖左右两侧。
5. “生效范围”选“白名单”时，只在你勾选的视频软件里自动显示，需要开启无障碍（点提示条会直接跳到留白的无障碍页）；选“全局”则开启后到处显示。
   - 白名单横屏、竖屏各一份：设置页当前在编辑哪一侧（底部大按钮切换），“生效范围”就是哪一侧的白名单。竖屏没单独设置过时沿用横屏那份。
6. “显示时机”选“仅播放时”：白名单软件里只在它真的在播放时显示，暂停后约 4 秒收起（切集、广告、缓冲不闪）。识别方式按可用程度自动选最准的一种：
   - **Shizuku**（可选）：安装并启动 Shizuku、在留白里授权后，能精确知道是哪个软件在播放，抖音、快手这类不规范使用媒体会话的软件也认得出。重启手机后需要重新启动 Shizuku。
   - **媒体会话**（可选）：授予“通知使用权”后，读取各软件的播放状态。只用来读播放状态，不读取任何通知内容。
   - **系统音频**（无需授权）：只能判断手机有没有媒体声音在播，配合前台软件使用。
   - 三种方式都识别不到无声视频。不需要这个功能就保持“始终显示”，此时完全不监听播放状态。
